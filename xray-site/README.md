# سایت + اینباندهای x-ui روی پورت‌های مشترک

برای هر اینباند x-ui فقط **دو پورت** لازم است:

1. **پورت اینباند x-ui** (مثلاً `123`)
2. **پورت عمومی روتر** که مردم به آن وصل می‌شوند (مثلاً `2082`)

روتر پورت عمومی را به **همان شماره** روی سرور فوروارد می‌کند (`2082` ← سرور:`2082`). روی آن پورت،
HAProxy اولین بایت‌های هر اتصال را نگاه می‌کند:

- **مرورگر** ← سایت
- **هر چیز دیگر** (کلاینت VPN) ← اینباند x-ui

```
اینترنت ──► IP عمومی:2082 ──(روتر)──► سرور:2082 ──► HAProxy ─┬─► سایت
                                                              └─► x-ui :123  (Turkey)
اینترنت ──► IP عمومی:2083 ──(روتر)──► سرور:2083 ──► HAProxy ─┬─► سایت
                                                              └─► x-ui :124  (Germany)
```

> روتر **نباید** مستقیم به پورت اینباند (`123`) فوروارد کند، چون آن‌وقت ترافیک از HAProxy رد نمی‌شود
> و سایت نمی‌آید. اگر الان روتر `2082 ← سرور:123` است، آن را به `2082 ← سرور:2082` تغییر دهید.

**x-ui دست نمی‌خورد.** در اپ‌های VPN آدرس = IP عمومی و پورت = پورت عمومی (`2082`) است، نه پورت اینباند.

## نصب

```bash
curl -fsSL -o install.sh https://raw.githubusercontent.com/eris4444/englishs/claude/admiring-planck-kx3x1l/xray-site/install.sh
```

```bash
sudo bash install.sh
```

لیست اینباندهای x-ui نشان داده می‌شود و برای هر کدام دو سؤال پرسیده می‌شود
(Enter یعنی مقدار داخل کروشه):

```
  x-ui inbound port (from the list above) [123]: 123          ← پورت اینباند
  Public port people connect to (on the router): 2082         ← پورت عمومی روتر
    Added: public port 2082 -> x-ui 123 "Turkey" vmess/tcp
  Add another inbound (y/n): y                                ← y برای اینباند بعدی
  x-ui inbound port (from the list above) [124]: 124
  Public port people connect to (on the router): 2083
    Added: public port 2083 -> x-ui 124 "Germany" vmess/tcp
  Add another inbound (y/n): n
```

سؤال «Add another inbound» حتماً جواب `y` یا `n` می‌خواهد (با کیبورد فارسی `غ` و `د` هم قبول است)؛
Enter خالی دوباره می‌پرسد.

جواب‌ها همان لحظه بررسی می‌شوند: اگر پورتی که دادید اینباند x-ui نباشد، دوباره می‌پرسد. اگر پورت عمومی
روی سرور آزاد نباشد (مثلاً خودش پورت یک اینباند باشد)، یک سؤال سوم می‌آید: «روتر به کدام پورت سرور فوروارد کند»
و یک پورت آزاد پیشنهاد می‌دهد.

در آخر دقیقاً می‌گوید در روتر چه فورواردهایی بسازید:

```
  In the router, forward (TCP):
    public 2082   ->  192.168.1.10:2082
    public 2083   ->  192.168.1.10:2083
```

نصب بدون سؤال (هر مورد `پورت‌اینباند:پورت‌عمومی`):

```bash
sudo PORTS="123:2082 124:2083" bash install.sh
```

## تغییر بعد از نصب

با منو:

```bash
sudo xray-site
```

```
  #   public port   x-ui inbound                 router forwards to
  1   2082          123 "Turkey" vmess/tcp       192.168.1.10:2082
  2   2083          124 "Germany" vmess/tcp      192.168.1.10:2083

  1) Add a port       ← اضافه کردن
  2) Change a port    ← تغییر (پورت عمومی یا اینباند)
  3) Remove a port    ← حذف
  4) Re-read x-ui and apply   ← بعد از تغییر اینباند در x-ui
  5) Change the website's internal port
  6) Status
  0) Exit
```

یا با دستور (همه‌جا «پورت» یعنی پورت عمومی):

| کار | دستور |
|---|---|
| دیدن لیست | `sudo xray-site list` |
| اضافه کردن | `sudo xray-site add 124 2083` (اینباند، پورت عمومی) |
| عوض کردن پورت عمومی | `sudo xray-site change 2083 2084` |
| عوض کردن اینباندِ یک پورت | `sudo xray-site change 2083 2083 1090` |
| حذف | `sudo xray-site remove 2083` |
| بعد از تغییر اینباند در x-ui | `sudo xray-site apply` |
| وضعیت | `sudo xray-site status` |

**هر تغییر امن است:** اول بررسی می‌شود، بعد اعمال و روی همه‌ی پورت‌ها تست می‌شود؛ اگر چیزی کار نکند،
تنظیمات قبلی خودکار برمی‌گردد. پورت حذف‌شده همان لحظه بسته می‌شود. اگر ufw یا firewalld فعال باشد،
پورت‌ها خودکار باز و بسته می‌شوند. برای هر پورت جدید یادتان باشد در **روتر** هم فوروارد بسازید.

## کدام اینباندها کار می‌کنند

همه تست شده‌اند (VPN وصل شد و سایت هم باز شد):

| اینباند در x-ui | شرط |
|---|---|
| VMess / VLESS / Trojan / Shadowsocks روی TCP | — |
| هر چیزی با TLS یا REALITY | — |
| WebSocket، HTTPUpgrade | — |
| gRPC بدون TLS | — |
| mixed و http (پروکسی) | — |
| XHTTP | path باید غیر از `/` باشد |
| TCP با HTTP header | path غیر از `/` **یا** یک Host (مثل `fast.com`) |
| mKCP / QUIC | کار نمی‌کند (UDP است) |

## محدودیت IP در x-ui

x-ui همه‌ی کاربرها را `127.0.0.1` می‌بیند و **محدودیت IP کاربرها کار نمی‌کند**، مگر اینکه در x-ui برای
آن اینباند **Proxy Protocol** را روشن کنید و `sudo xray-site apply` بزنید.

## تغییر سایت

فایل‌ها در `/var/www/xray-site` است؛ `index.html` را عوض کنید یا فایل‌های خودتان را بگذارید.

## تست

از **بیرون** شبکه‌ی خانه (مثلاً اینترنت موبایل) `http://IP-عمومی:2082` را باز کنید؛ باید سایت بیاید.

## حذف

x-ui دست نمی‌خورد؛ فقط سایت و تفکیک‌کننده حذف می‌شوند:

```bash
sudo xray-site uninstall
```
