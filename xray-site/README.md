# سایت + اینباند x-ui روی یک پورت

روتر پورت عمومی `8080` را به پورت `1234` سرور می‌فرستد. این اسکریپت روی `1234` یک «تفکیک‌کننده»
(HAProxy) می‌گذارد که اولین بایت‌های هر اتصال را نگاه می‌کند:

- **مرورگر** (کسی که `http://IP:8080` را باز کند) ← سایت (nginx روی `127.0.0.1`)
- **هر چیز دیگر** (کلاینت VPN) ← اینباند x-ui روی پورت `8080`

```
اینترنت ──► IP عمومی:8080 ──(روتر)──► سرور:1234 ──► HAProxy ─┬─► سایت   (nginx، 127.0.0.1:8081)
                                                              └─► x-ui   (اینباند روی 8080)
```

**x-ui دست نمی‌خورد.** همان لینک‌هایی که از پنل x-ui می‌گیرید کار می‌کنند؛ فقط در لینک، آدرس باید
**IP عمومی** و پورت **8080** باشد (نه IP داخلی سرور).

## نصب

روی سرور، با دسترسی root:

```bash
curl -fsSL -o install.sh https://raw.githubusercontent.com/eris4444/englishs/claude/admiring-planck-kx3x1l/xray-site/install.sh
```

```bash
sudo bash install.sh
```

اسکریپت تنظیمات اینباند پورت 8080 را از دیتابیس x-ui (`/etc/x-ui/x-ui.db`، فقط خواندنی) می‌خواند
و قوانین تفکیک را بر اساس آن می‌سازد. **هر بار که در x-ui ترنسپورت، path یا Proxy Protocol را عوض کردید،
اسکریپت را دوباره اجرا کنید.**

## کدام اینباندها کار می‌کنند

همه‌ی این‌ها تست شده‌اند (VPN وصل شد و سایت هم باز شد):

| اینباند در x-ui | شرط |
|---|---|
| VLESS / VMess / Trojan / Shadowsocks روی TCP | — |
| هر چیزی با TLS یا REALITY | — |
| WebSocket، HTTPUpgrade | — (هر path) |
| gRPC بدون TLS | — |
| XHTTP | path باید غیر از `/` باشد |
| TCP با HTTP header | path غیر از `/` **یا** یک Host (مثل `fast.com`) |
| mKCP / QUIC | کار نمی‌کند (UDP است) |

اگر اینباند شما در دو ردیف آخر جدول باشد، اسکریپت قبل از هر تغییری متوقف می‌شود و می‌گوید در x-ui چه چیزی را عوض کنید.

## محدودیت IP در x-ui

چون همه‌ی اتصال‌ها از HAProxy می‌آیند، x-ui همه را `127.0.0.1` می‌بیند و **محدودیت IP کاربرها کار نمی‌کند**.
برای درست شدنش، در x-ui برای این اینباند **Proxy Protocol** را روشن کنید و اسکریپت را دوباره اجرا کنید؛
اسکریپت خودش تشخیص می‌دهد و IP واقعی کاربر را به x-ui می‌فرستد.
(بعد از آن، اتصال مستقیم از داخل شبکه‌ی خانه به `:8080` کار نمی‌کند؛ از `:1234` استفاده کنید.)

## تنظیمات

| متغیر | پیش‌فرض | توضیح |
|---|---|---|
| `SERVER_PORT` | `1234` | پورتی روی سرور که روتر به آن فوروارد می‌کند |
| `XUI_PORT` | `8080` | پورت اینباند x-ui |
| `PUBLIC_PORT` | `8080` | پورت عمومی (فقط برای نمایش در خلاصه) |
| `SITE_PORT` | `8081` یا اولین پورت آزاد | پورت داخلی سایت روی `127.0.0.1` |
| `PUBLIC_IP` | خودکار | IP عمومی، برای نمایش در خلاصه |
| `XUI_DB` | `/etc/x-ui/x-ui.db` | مسیر دیتابیس x-ui |

```bash
sudo SERVER_PORT=1234 XUI_PORT=8080 bash install.sh
```

## تغییر سایت

فایل‌های سایت در `/var/www/xray-site` است. `index.html` را عوض کنید یا فایل‌های خودتان را آنجا بگذارید؛
ری‌استارت لازم نیست. اسکریپت روی `index.html` موجود چیزی نمی‌نویسد.

## تست

از **بیرون** از شبکه‌ی خانه (مثلاً اینترنت موبایل) `http://IP-عمومی:8080` را باز کنید؛ باید سایت بیاید.
از داخل شبکه‌ی خانه، `IP-داخلی:8080` مستقیم به x-ui می‌رود؛ برای دیدن سایت از داخل، `IP-داخلی:1234` را باز کنید.

## دستورهای مفید

```bash
systemctl status xray-site nginx
```

```bash
journalctl -u xray-site -n 50
```

```bash
cat /etc/xray-site/haproxy.cfg
```

## حذف

x-ui دست نمی‌خورد؛ فقط سایت و تفکیک‌کننده حذف می‌شوند:

```bash
sudo systemctl disable --now xray-site && sudo rm -rf /etc/xray-site /etc/systemd/system/xray-site.service /etc/nginx/conf.d/xray-site.conf && sudo systemctl reload nginx
```
