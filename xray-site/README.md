# سایت + اینباندهای x-ui روی پورت‌های مشترک

روی هر پورتی که در لیست باشد، HAProxy اولین بایت‌های هر اتصال را نگاه می‌کند:

- **مرورگر** ← سایت (nginx روی `127.0.0.1`)
- **هر چیز دیگر** (کلاینت VPN) ← اینباند x-ui‌ای که آن پورت به آن وصل شده

```
اینترنت ──► IP عمومی:8080 ──(روتر)──► سرور:1234 ──► HAProxy ─┬─► سایت
                                                              └─► x-ui :8080
اینترنت ──► IP عمومی:2345 ──(روتر)──► سرور:2345 ──► HAProxy ─┬─► سایت
                                                              └─► x-ui :8443
```

می‌شود هر تعداد پورت داشت؛ چند پورت می‌توانند به یک اینباند بروند یا هر کدام به اینباند جدا.
**x-ui دست نمی‌خورد** و لینک‌های پنل x-ui همان‌طور کار می‌کنند (آدرس = IP عمومی، پورت = پورت عمومی).

## نصب

```bash
curl -fsSL -o install.sh https://raw.githubusercontent.com/eris4444/englishs/claude/admiring-planck-kx3x1l/xray-site/install.sh
```

```bash
sudo bash install.sh
```

نصب‌کننده لیست اینباندهای x-ui را نشان می‌دهد و برای هر پورت سه سؤال می‌پرسد
(Enter یعنی همان مقدار داخل کروشه):

```
Port on this server that the router forwards to [1234]:        ← پورت سرور (مقصد فوروارد روتر)
x-ui inbound port to send VPN traffic to [8080]:               ← پورت اینباند x-ui
Public port people use (the router's outside port) [8080]:     ← پورت عمومی (فقط برای نمایش)
Add another port (y/n) [n]:                                    ← y برای اضافه کردن پورت بعدی
```

نصب بدون سؤال (فرمت هر مورد `پورت‌سرور:پورت‌x-ui:پورت‌عمومی`؛ پورت عمومی اختیاری است):

```bash
sudo PORTS="1234:8080:8080 2345:8443" bash install.sh
```

اگر نسخه‌ی قبلی نصب است، اجرای دوباره‌ی `install.sh` پورت‌های فعلی را نگه می‌دارد.

## تغییر پورت‌ها بعد از نصب

با منو:

```bash
sudo xray-site
```

```
  #   server port   x-ui port   public port   x-ui inbound
  1   1234          8080        8080          "home" vless/tcp/none
  2   2345          8443        2345          "work" vless/ws/none

  1) Add a port          ← اضافه کردن پورت
  2) Change a port       ← تغییر پورت
  3) Remove a port       ← حذف پورت
  4) Re-read x-ui and apply   ← بعد از تغییر اینباند در x-ui
  5) Change the website's internal port
  6) Status
  0) Exit
```

یا با دستور:

| کار | دستور |
|---|---|
| دیدن لیست | `sudo xray-site list` |
| اضافه کردن پورت | `sudo xray-site add 2345 8443` |
| … با پورت عمومی متفاوت | `sudo xray-site add 2345 8443 9000` |
| عوض کردن پورت سرور | `sudo xray-site change 2345 2346` |
| عوض کردن اینباند یک پورت | `sudo xray-site change 2345 2345 8444` |
| حذف پورت | `sudo xray-site remove 2345` |
| جابه‌جایی پورت داخلی سایت | `sudo xray-site site-port 8090` |
| بعد از تغییر اینباند در x-ui | `sudo xray-site apply` |
| وضعیت | `sudo xray-site status` |

**هر تغییر امن است:** اول همه‌چیز ساخته و بررسی می‌شود؛ بعد از اعمال، سایت و x-ui روی همه‌ی پورت‌ها
تست می‌شوند و اگر چیزی کار نکند، تنظیمات قبلی خودکار برمی‌گردد. اگر پورتی دست برنامه‌ی دیگری باشد،
یا اینباند x-ui جواب ندهد، تغییر اصلاً اعمال نمی‌شود و پیام خطا می‌گوید چه کار کنید.

پورت حذف‌شده همان لحظه بسته می‌شود (اتصال‌های باز تا ۱۰ دقیقه ادامه دارند). اگر ufw یا firewalld
فعال باشد، پورت‌های جدید باز و پورت‌های حذف‌شده بسته می‌شوند.

لیست پورت‌ها در `/etc/xray-site/xray-site.conf` است؛ اگر دستی ویرایشش کردید، `sudo xray-site apply` بزنید.

> یادتان باشد برای هر پورت جدید، در **روتر** هم فوروارد بسازید (پورت عمومی ← IP سرور : پورت سرور).

## کدام اینباندها کار می‌کنند

همه تست شده‌اند (VPN وصل شد و سایت هم باز شد):

| اینباند در x-ui | شرط |
|---|---|
| VLESS / VMess / Trojan / Shadowsocks روی TCP | — |
| هر چیزی با TLS یا REALITY | — |
| WebSocket، HTTPUpgrade | — (هر path) |
| gRPC بدون TLS | — |
| XHTTP | path باید غیر از `/` باشد |
| TCP با HTTP header | path غیر از `/` **یا** یک Host (مثل `fast.com`) |
| mKCP / QUIC | کار نمی‌کند (UDP است) |

## محدودیت IP در x-ui

x-ui همه‌ی کاربرها را `127.0.0.1` می‌بیند و **محدودیت IP کاربرها کار نمی‌کند**، مگر اینکه در x-ui برای
آن اینباند **Proxy Protocol** را روشن کنید و `sudo xray-site apply` بزنید؛ از آن به بعد IP واقعی به x-ui می‌رسد.
(بعدش اتصال مستقیم از داخل شبکه‌ی خانه به پورت خود اینباند کار نمی‌کند؛ از پورت مشترک استفاده کنید.)

## تغییر سایت

فایل‌ها در `/var/www/xray-site` است؛ `index.html` را عوض کنید یا فایل‌های خودتان را بگذارید. ری‌استارت لازم نیست.

## تست

از **بیرون** شبکه‌ی خانه (مثلاً اینترنت موبایل) `http://IP-عمومی:پورت-عمومی` را باز کنید؛ باید سایت بیاید.

## حذف

x-ui دست نمی‌خورد؛ فقط سایت و تفکیک‌کننده حذف می‌شوند (فایل‌های سایت می‌مانند):

```bash
sudo xray-site uninstall
```
