# xray-site 3.0: سایت + x-ui / مرزبان روی پورت‌های مشترک

روی هر پورت مشترک، HAProxy اولین بایت‌های هر اتصال را نگاه می‌کند:

- **مرورگر** ← سایت (یکی از ۹ قالب آماده، یا سایت خودتان؛ با http و اگر گواهی دارید https)
- **کلاینت VPN** ← اینباند x-ui یا مرزبانِ همان پورت (VMess، VLESS، Trojan، Shadowsocks، TLS، REALITY، WebSocket و ...)

به‌علاوه نصب خودکار **پنل 3x-ui (ثنایی)**، **مرزبان (از فورک eris4444/Marzban)** و **نود مرزبان**، با تنظیم دسترسی
از شبکه‌ی خانه و از بیرون.

```
اینترنت ──► IP عمومی:2082 ──(روتر)──► سرور:2082 ──► HAProxy ─┬─► سایت (http و https)
                                                              └─► x-ui :123  (Turkey)
```

**x-ui دست نمی‌خورد.** در اپ‌های VPN آدرس = IP عمومی و پورت = پورت عمومی (مثلاً `2082`).

## نصب و به‌روزرسانی

```bash
curl -fsSL -o install.sh https://raw.githubusercontent.com/eris4444/englishs/claude/admiring-planck-kx3x1l/xray-site/install.sh
```

```bash
sudo bash install.sh
```

نصب برای هر اینباند دو پورت می‌پرسد (پورت اینباند x-ui و پورت عمومی روتر) و بعد قالب سایت را.
اگر قبلاً نصب کرده‌اید، پورت‌ها حفظ می‌شوند و فقط یک بار قالب سایت پرسیده می‌شود (Enter = همان سایت فعلی).
`install.sh` یک فایل کامل است: قالب‌ها داخل خودش هستند و چیز دیگری دانلود نمی‌کند.

به‌روزرسانی‌های بعدی از خود منو: گزینه‌ی **16) Update xray-site**.

## قالب‌های سایت

| # | قالب | توضیح |
|---|---|---|
| 1 | `download` | دانلود سنتر با جست‌وجو و دسته‌بندی |
| 2 | `blog` | وبلاگ شخصی |
| 3 | `company` | سایت شرکت فناوری |
| 4 | `shop` | فروشگاه اینترنتی با سبد خرید |
| 5 | `hosting` | شرکت هاستینگ با تعرفه‌ها |
| 6 | `portfolio` | نمونه‌کار طراح یا عکاس |
| 7 | `soon` | «به‌زودی» با شمارش معکوس |
| 8 | `status` | صفحه‌ی وضعیت سرویس (انگلیسی) |
| 9 | `nginx` | صفحه‌ی پیش‌فرض «Welcome to nginx!» |
| 10 | `custom` | فایل‌های خودتان در `/var/www/xray-site` |

همه‌ی قالب‌ها بدون هیچ فایل خارجی‌اند (سریع، و با فیلتر بودن CDNها هم کامل باز می‌شوند) و روی موبایل هم درست نمایش داده می‌شوند.

مثل یک سایت واقعی: favicon (هم `.ico` هم `.svg`)، `robots.txt`، صفحه‌ی ۴۰۴ هم‌رنگ قالب، توضیح و رنگ صفحه در `<head>`،
فشرده‌سازی gzip و کش برای تصویرها. دکمه‌های دانلود سنتر به صفحه‌ی دانلود رسمی هر نرم‌افزار می‌روند.
قالب `nginx` دقیقاً همان صفحه‌ی پیش‌فرض nginx می‌ماند (بدون favicon و ۴۰۴ اختصاصی، مثل nginx واقعی).

## گواهی SSL و HTTPS

**گواهی رایگان (منوی 8):** دامنه باید به IP عمومی شما اشاره کند. دو روش تأیید:

- **Cloudflare DNS (پیشنهادی):** هیچ پورتی لازم نیست باز باشد. دامنه روی Cloudflare باشد و یک API Token
  با دسترسی «Edit zone DNS» بسازید (dash.cloudflare.com ← My Profile ← API Tokens). wildcard (`*.domain`) هم می‌شود.
- **HTTP:** روتر باید پورت عمومی `80` را به یکی از پورت‌های سرور (پیش‌فرض 80) فوروارد کند.

**گواهی خودتان (منوی 9):** متن `-----BEGIN CERTIFICATE-----` و کلید را بچسبانید، یا مسیر فایل‌ها را بدهید.
اسکریپت بررسی می‌کند که کلید مال همان گواهی باشد.

**HTTP / HTTPS سایت (منوی 11):** سه کلید جدا:

| کلید | روشن | خاموش |
|---|---|---|
| **HTTP** | `http://IP:2082` سایت را نشان می‌دهد | اتصال بدون هیچ جوابی بسته می‌شود (انگار سایتی نیست) |
| **HTTPS** | `https://دامنه:2082` با گواهی معتبر | سایتی روی https نیست؛ گواهی‌های انتخاب‌شده یادش می‌ماند |
| **Redirect** | مرورگری که `http://دامنه` را باز کند به `https://دامنه` می‌رود (حتی وقتی HTTP خاموش است) | — |

مثلاً «HTTP خاموش + HTTPS روشن + Redirect روشن» یعنی سایت فقط با https و دامنه باز می‌شود، `http://دامنه` به
https می‌رود و باز کردن IP خالی هیچ چیزی نشان نمی‌دهد. **VPN در هیچ حالتی تحت تأثیر نیست** (حتی اینباندهای
WebSocket یا XHTTP که خودشان روی HTTP هستند).

HTTPS روی همان پورت‌های مشترک است؛ اتصال‌های TLS با نام‌های دیگر (اینباندهای TLS یا REALITY در x-ui) مثل قبل
به x-ui می‌روند. اگر یک اینباند x-ui از همان دامنه‌ی سایت استفاده کند، اسکریپت قبل از هر تغییری خبر می‌دهد.

**استفاده در x-ui:** منوی 10 ← 3 مسیر فایل‌ها را نشان می‌دهد (مثلاً `/etc/xray-site/certs/vpn.example.com/fullchain.pem`
و `privkey.pem`) تا در تنظیمات پنل x-ui یا TLS اینباند بگذارید. با گزینه‌ی «Restart x-ui after a renewal»،
x-ui بعد از هر تمدید خودکار ری‌استارت می‌شود.

## پنل 3x-ui (ثنایی) — منوی 18

- **نصب یا به‌روزرسانی:** نصب‌کننده‌ی رسمی MHSanaei اجرا می‌شود (سؤال‌هایش را خودتان جواب می‌دهید). اگر x-ui از قبل
  نصب است، اول از دیتابیس (`/etc/x-ui/x-ui.db`) نسخه‌ی پشتیبان در `/etc/xray-site/backups` گرفته می‌شود؛ اینباندها و کاربرها می‌مانند.
- **دسترسی:** نام کاربری و رمز جدید (اختیاری)، گواهی برای HTTPS پنل (از گواهی‌های منوی 8 و 9)، پورت عمومی روتر.
  آخرش آدرس از شبکه‌ی خانه و از بیرون و فوروارد لازم در روتر را نشان می‌دهد. با گواهی، بعد از هر تمدید x-ui خودکار ری‌استارت می‌شود.

## پنل مرزبان — منوی 19

- **از فورک خودتان** (`eris4444/Marzban`) روی همین سرور با Docker ساخته (build) می‌شود؛ بار اول چند دقیقه طول می‌کشد.
  Docker اگر نباشد نصب می‌شود (اول از مخزن خود Debian/Ubuntu که از ایران باز است).
- **Docker Hub از ایران بسته است:** اگر در دسترس نباشد، میرورها خودکار تنظیم می‌شوند
  (پیش‌فرض: arvancloud، focker، docker.ir؛ با متغیر `DOCKER_MIRRORS` عوض می‌شود).
- **دسترسی:** مرزبان فقط با HTTPS به دستگاه‌های دیگر جواب می‌دهد. یا یک گواهی از منوی 8/9 انتخاب کنید (دسترسی با دامنه،
  بدون هشدار)، یا یک گواهی self-signed برای IP شبکه‌ی خانه ساخته می‌شود (مرورگر یک بار هشدار می‌دهد).
  نام کاربری `admin` و یک رمز تصادفی ساخته و نمایش داده می‌شود (گزینه‌ی 3 دوباره نشانش می‌دهد).
- **آدرس در لینک‌ها (گزینه‌ی 4):** در لینک‌های کاربران، دامنه یا IP عمومی گذاشته می‌شود و اگر اینباندی از طریق xray-site
  با سایت شریک است، پورت عمومی روتر.
- **با سایت روی یک پورت:** اینباندهای مرزبان مثل x-ui در «Add a port» دیده می‌شوند (با برچسب `[mz]`).
- **به‌روزرسانی (گزینه‌ی 5):** آخرین کد فورک دریافت و دوباره ساخته می‌شود؛ کاربرها و تنظیمات در `/var/lib/marzban` می‌مانند.

## نودهای مرزبان — منوی 20

- **نود روی سرور دیگر (مثلاً ترکیه یا آلمان):** نام و IP آن سرور را بدهید. بعد یا **خودکار با SSH** (کاربر root،
  رمز یا کلید) نصب می‌شود، یا **یک دستور** نشان داده می‌شود که روی آن سرور اجرا کنید. بعد نود خودکار در پنل اضافه
  می‌شود و صبر می‌کند تا وصل شود. روی سرور نود پورت‌های `62050` و `62051` باید باز باشند.
- **همین سرور را نود یک پنل دیگر کردن:** یا با آدرس و رمز آن پنل (گواهی گرفته و نود خودکار وصل می‌شود)، یا با
  چسباندن گواهی نود از پنل.
- **نود روی همان سروری که پنل مرزبان هست نصب نمی‌شود:** هسته‌ی خود پنل همه‌ی اینباندها را روی همان سرور اجرا
  می‌کند، پس نود روی همان پورت‌ها با آن تداخل دارد. اسکریپت این را توضیح می‌دهد و نصب نمی‌کند.

## نکته‌ها

- محدودیت IP کاربرها در x-ui فقط وقتی کار می‌کند که برای اینباند **Proxy Protocol** را روشن کنید و گزینه‌ی 4 را بزنید.
- برای هر پورت جدید، در **روتر** هم فوروارد بسازید (پورت عمومی ← IP سرور : همان پورت).
- حذف (گزینه‌ی 17) x-ui را دست نمی‌زند و گواهی‌ها را در `/etc/xray-site/certs` نگه می‌دارد.
